# 财富规划建议书编辑器

面向理财经理的对客财富规划建议书编辑器原型：按模块拖拽组装建议书，逐个模块生成内容，在线编辑文字，预览后导出 Word。

> 页面中的客户、产品与金额均为虚构示例数据。

## 功能

- **模块库拖拽**：9 个模块（封面、客户画像、资产负债现状、风险测评、目标缺口、资产配置建议、产品推荐、情景测算、风险揭示）。可拖入文档的任意位置，也可点击添加；封面、免责声明只能各添加一次，免责声明为必选、不可删除。
- **逐模块生成**：新加入的模块为“待生成”，点击模块上的「生成」只生成这一个模块；也可一键生成全部待生成模块。
- **在线编辑**：生成后的段落、标题、表格单元格都可以直接修改；粘贴时只保留纯文本，避免外部样式混入。改过的模块标记为“已人工修改”，重新生成前需要二次确认。
- **排序**：拖动模块卡片，或用上移/下移按钮。
- **预览**：只读成稿视图，带页眉页脚，支持 75% / 100% / 125% 缩放；未生成的模块会醒目提示。
- **导出 Word**：浏览器端直接生成 `.docx`，导出内容就是页面上（含人工修改后）的内容。

## Word 导出的防跳页处理

`src/exportDocx.js` 中统一设置了 Word 分页控制属性：

| 处理 | 对应 Word 属性 |
|---|---|
| 章节标题不会孤零零落在页底 | 标题“与下段同页”（keepNext）+“段中不分页”（keepLines） |
| 避免页底只剩一行 | 正文“孤行控制”（widowControl） |
| 表格行不被拆到两页 | 行属性 cantSplit |
| 表格跨页时重复表头 | 标题行重复（tableHeader） |
| 8 行以内的小表整体同页 | 除最后一行外每行 keepNext |
| 图表与图题同页、不漂移 | 图题/图片 keepNext，图片为嵌入型 |
| 封面后另起一页且不产生空白页 | 用“段前分页”（pageBreakBefore），不插硬分页符和空段落 |

页眉（标题与客户名）、页脚（第 X 页 / 共 Y 页）自动生成，封面页不显示页眉页脚。

## 本地运行

```bash
npm install
npm run dev      # 开发模式 http://localhost:5173
npm run build    # 生产构建，输出到 dist/
```

## 部署

推送到 `main` 分支后，GitHub Actions（`.github/workflows/deploy.yml`）会自动构建并发布到 GitHub Pages。
首次使用需要在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

## 目录结构

```
src/
  App.vue                    三栏编辑器：模块库 / 文档 / 模块设置，预览、导出
  modules.js                 模块定义与内容生成（模拟后端接口）
  mockData.js                示例客户数据
  exportDocx.js              结构化内容 → .docx（含防跳页设置）
  components/BlockView.vue   各类内容块的渲染（标题、段落、表格、饼图、列表、封面）
  components/EditableText.vue 纯文本可编辑组件
```

## 接入真实系统

- `modules.js` 中的 `generateModule(type, options)` 目前返回本地示例内容，替换为调用后端生成接口即可（如 `POST /api/proposal/modules/:type/generate`）。
- 内容采用结构化“块”数据（标题 / 段落 / 表格 / 饼图 / 列表），页面渲染与 Word 导出共用同一份数据。如需更高保真的 Word 版式（品牌模板、Word 原生图表），可把这份块数据交给后端，用 poi-tl 等模板引擎按模块子模板合并生成。
